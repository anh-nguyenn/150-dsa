# Advanced Graphs

Advanced graph problems add a cost model or an ordering constraint. Dijkstra handles non-negative weighted shortest paths; Bellman-Ford handles a bounded number of edges; Prim and Kruskal build minimum spanning trees; topological sort orders dependencies.

Reach for them when edges have weights, when the number of stops is bounded, or when the answer is an ordering rather than a path.

It assumes you can choose the right algorithm from the graph's properties, not from its name.
