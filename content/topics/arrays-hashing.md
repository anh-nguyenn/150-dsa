# Arrays & Hashing

Arrays & Hashing is the pattern of answering questions about what you have already seen. A set answers "is this here?"; a map answers "where, or how many?"; a frequency array answers the same question when the key space is small.

Reach for it when a nested loop is really asking the same lookup over and over: a complement, a duplicate, a count, a group, or a prefix state. The trade is usually memory for time.

It assumes comfort with array indexing and the idea that dictionary operations are constant time on average.
