Given two strings `s1` and `s2`, decide whether `s2` contains a contiguous substring that is a rearrangement of `s1`.

**Example**

```text
s1 = "ab", s2 = "eidbaooo"  ->  true   ("ba")
s1 = "ab", s2 = "eidboaoo"  ->  false
```

**Constraints, in plain words**

- Both strings have between 1 and 10,000 characters.
- Characters are lowercase English letters.
- A rearrangement uses exactly the same letters with the same counts.
- The matching part of `s2` must be contiguous.
