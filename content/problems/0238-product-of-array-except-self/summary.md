Given an integer list, return a new list where position `i` contains the product of every value except `nums[i]`.

**Example**

```text
nums = [1, 2, 3, 4]  ->  [24, 12, 8, 6]
nums = [0, 2, 3]     ->  [6, 0, 0]
```

**Constraints, in plain words**

- Between 2 and 100,000 numbers.
- Each value is between -30 and 30.
- Products can be large, but Python integers handle them.
- Division is not part of the intended solution, and zeros make it unreliable anyway.
