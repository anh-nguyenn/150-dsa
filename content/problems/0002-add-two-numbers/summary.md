Two non-negative integers are stored in linked lists with the ones digit first. Add the numbers and return the sum in the same reversed-digit form.

**Example**

```text
[2, 4, 3] represents 342
[5, 6, 4] represents 465
sum 807  ->  [7, 0, 8]
```

**Constraints, in plain words**

- Each list holds between 1 and 100 digits.
- Every digit is between 0 and 9.
- Numbers have no leading zeros, except the number zero itself.
- The result may have one more digit than either input.
