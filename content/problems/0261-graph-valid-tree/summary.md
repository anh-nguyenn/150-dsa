You are given `n` nodes labeled `0` through `n - 1` and a list of undirected edges. Decide whether the nodes and edges form a valid tree: the graph must be connected and must contain no cycle.

**Examples**

```text
n = 5, edges = [[0,1],[0,2],[0,3],[1,4]]  -> true
n = 4, edges = [[0,1],[2,3]]              -> false
```

**Constraints, in plain words**

- Between 1 and 2,000 nodes.
- Up to 5,000 undirected edges, with no repeated edge.
- An edge never connects a node to itself.
- Node labels are always inside the valid range.
