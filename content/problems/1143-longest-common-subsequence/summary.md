Two strings are given. A subsequence keeps characters in their original relative order but may skip characters. Return the length of the longest string that is a subsequence of both inputs.

For `text1 = "abcde"` and `text2 = "ace"`, the answer is `3` because `"ace"` appears in order in both. For `"abc"` and `"abc"`, the answer is `3`.

**Constraints, in plain words**

- Each string has between 0 and 1000 characters; the official inputs are non-empty, but empty strings are handled here.
- Characters are lowercase English letters.
- A subsequence does not need to be contiguous.
