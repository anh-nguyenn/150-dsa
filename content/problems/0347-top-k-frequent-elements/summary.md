Given an integer list and a number `k`, return the `k` values that occur most often. The problem guarantees a unique answer, so there is only one correct set of values. Return them in any order.

**Example**

```text
nums = [1, 1, 1, 2, 2, 3], k = 2  ->  [1, 2]
```

**Constraints, in plain words**

- Between 1 and 100,000 numbers.
- `k` is between 1 and the number of distinct values.
- Values may be negative.
- The set of top `k` values is guaranteed to be unique.
