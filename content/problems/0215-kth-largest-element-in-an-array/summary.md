Given an integer array and a rank `k`, return the kth largest element. The array is not sorted, and duplicate values count as separate positions. For example, the second largest value in `[3, 2, 3, 1]` is `3`.

**Example**

```text
nums = [3, 2, 1, 5, 6, 4], k = 2  ->  5
```

**Constraints, in plain words**

- Between 1 and 100,000 numbers.
- `k` is between 1 and the length of the array.
- Values are between -10,000 and 10,000.
- Duplicates count as separate values.
