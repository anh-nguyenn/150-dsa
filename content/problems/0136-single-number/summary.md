Every value in the array appears exactly twice except for one value, which appears once. Return that lone value.

**Example**

```text
nums = [4, 1, 2, 1, 2]  ->  4
```

**Constraints, in plain words**

- Between 1 and 30,000 numbers.
- Values are between -30,000 and 30,000.
- Every value occurs twice except one, which occurs once.
- The array is not necessarily sorted.
