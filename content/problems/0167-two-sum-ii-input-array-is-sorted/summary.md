Given an array sorted in ascending order and a target, return the 1-based positions of the two values that add up to the target. Exactly one pair is guaranteed.

**Example**

```text
numbers = [2, 7, 11, 15], target = 9  ->  [1, 2]
```

**Constraints, in plain words**

- Between 2 and 30,000 numbers.
- Values are between -1,000 and 1,000.
- The array is sorted from smallest to largest.
- Exactly one answer exists, and the same position cannot be used twice.
- Return positions starting from 1, with the smaller position first.
