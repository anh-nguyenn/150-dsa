Given stone weights, repeatedly take the two heaviest stones and smash them together. If their weights are equal, both disappear. Otherwise the heavier one survives with weight equal to the difference. Return the weight of the last remaining stone, or 0 if none remain.

**Example**

```text
[2, 7, 4, 1, 8, 1]  ->  1
```

**Constraints, in plain words**

- Between 1 and 30 stones.
- Each weight is between 1 and 1,000.
- The process always waits for the two heaviest stones, so the order of the input does not matter.
