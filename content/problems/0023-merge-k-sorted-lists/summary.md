Merge `k` sorted linked lists into one sorted linked list. Reuse the existing nodes and return the head of the combined list.

**Example**

```text
[[1, 4, 5], [1, 3, 4], [2, 6]]  ->  [1, 1, 2, 3, 4, 4, 5, 6]
```

**Constraints, in plain words**

- There can be between 0 and 10,000 lists.
- Across all lists there are at most 10,000 nodes.
- Values are between -10,000 and 10,000.
- Every individual list is already sorted in non-decreasing order.
