A strictly increasing array was rotated some number of times. Find its smallest value.

```text
[3,4,5,1,2]      ->  1
[4,5,6,7,0,1,2]  ->  0
```

**Constraints, in plain words**

- Between 1 and 5,000 numbers.
- All values are distinct.
- The array is a sorted sequence that may have been rotated, including the possibility of no rotation.
- The answer is the single point where the order wraps around.
