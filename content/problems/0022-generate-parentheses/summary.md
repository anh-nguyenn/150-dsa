Given a number of pairs `n`, return every string of `n` opening and `n` closing parentheses that is correctly balanced. The strings may be returned in any order.

**Example**

```text
n = 3
-> ["((()))", "(()())", "(())()", "()(())", "()()()"]
```

**Constraints, in plain words**

- `n` is between 1 and 8 in the official input.
- Every result uses exactly `n` pairs.
- At no point may a closing parenthesis appear before its matching opening parenthesis.
- The number of valid strings is the nth Catalan number.
