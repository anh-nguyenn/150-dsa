Given a string `s`, return a longest contiguous substring that reads the same forwards and backwards. When several substrings tie for the maximum length, any one of them is acceptable.

**Examples**

```text
s = "cbbd"     ->  "bb"
s = "racecar"  ->  "racecar"
```

**Constraints, in plain words**

- Between 1 and 1,000 characters.
- The string contains only lowercase English letters.
- Single characters count as palindromes.
