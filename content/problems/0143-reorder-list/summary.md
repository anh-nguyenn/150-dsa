Rearrange a linked list in place from `L0 -> L1 -> ... -> Ln` into `L0 -> Ln -> L1 -> Ln-1 -> ...`. Change links between nodes, not the values stored in them.

**Examples**

```text
[1, 2, 3, 4]        ->  [1, 4, 2, 3]
[1, 2, 3, 4, 5]     ->  [1, 5, 2, 4, 3]
```

**Constraints, in plain words**

- The list holds between 1 and 50,000 nodes.
- Values are between -1,000 and 1,000.
- The reordering happens in place; only node links may change.
