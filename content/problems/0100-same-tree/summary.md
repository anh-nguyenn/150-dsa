Given the roots of two binary trees, return true when the trees have the same shape and the same value at every corresponding node.

`[1, 2, 3]` and `[1, 2, 3]` are the same. `[1, 2]` and `[1, null, 2]` are not, because the second tree puts `2` on the right instead of the left.

**Constraints, in plain words**

- Each tree has between 0 and 100 nodes.
- Node values are between -10,000 and 10,000.
- Missing children appear as `null` in the level-order input.
