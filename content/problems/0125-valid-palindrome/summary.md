Decide whether a string reads the same forwards and backwards after ignoring everything that is not a letter or digit and treating upper and lower case as equal.

**Example**

```text
"A man, a plan, a canal: Panama"  ->  true
"race a car"                      ->  false
```

**Constraints, in plain words**

- The string has between 1 and 200,000 characters.
- It can contain letters, digits, spaces, and punctuation.
- Only letters and digits count, and case does not matter.
