Given an unsorted integer list, return the length of the longest run of consecutive values. Values do not need to appear next to each other in the list, and duplicates count only once. Consecutive values differ by exactly 1.

**Example**

```text
[100, 4, 200, 1, 3, 2]        ->  4   (1, 2, 3, 4)
[0, 3, 7, 2, 5, 8, 4, 6, 0, 1]  ->  9   (0 through 8)
```

**Constraints, in plain words**

- Between 0 and 100,000 numbers.
- Values are between -10^9 and 10^9.
- Linear time is expected, so sorting is too slow.
