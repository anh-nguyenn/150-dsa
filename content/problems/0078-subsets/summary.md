Given a list of distinct integers, return every possible subset, including the empty subset. Subsets can appear in any order.

**Example**

```text
nums = [1, 2, 3]
-> [[], [1], [1, 2], [1, 2, 3], [1, 3], [2], [2, 3], [3]]
```

**Constraints, in plain words**

- The official input has between 1 and 10 numbers.
- Every number is different.
- Values fit between -10 and 10.
- The empty subset is part of the answer.
