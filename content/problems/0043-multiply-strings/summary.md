Multiply two non-negative integers given as decimal strings and return the product as a decimal string. The inputs can be too long for ordinary integer types, so work digit by digit.

**Example**

```text
"2"   * "3"   -> "6"
"123" * "456" -> "56088"
```

**Constraints, in plain words**

- Each string has between 1 and 200 digits.
- The strings contain only digits and have no leading zeros unless the value is exactly `"0"`.
- Do not convert either whole string to a built-in integer.
- An `m`-digit number times an `n`-digit number has at most `m + n` digits.
