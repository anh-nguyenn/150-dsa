Reverse a singly linked list and return its new head. Every node points forward, so the links themselves have to be turned around.

**Example**

```text
1 -> 2 -> 3 -> 4 -> 5   becomes   5 -> 4 -> 3 -> 2 -> 1
```

**Constraints, in plain words**

- The list can hold anywhere from 0 to 5,000 nodes.
- Values range from -5,000 to 5,000.
- An empty list is allowed and should produce an empty list.
