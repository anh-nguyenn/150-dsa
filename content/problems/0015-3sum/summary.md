Find every group of three positions whose values add to zero. The same triplet must not appear twice, and neither the order of the triplets nor the order inside a triplet matters.

**Example**

```text
nums = [-1, 0, 1, 2, -1, -4]
->  [-1, -1, 2] and [-1, 0, 1]
```

**Constraints, in plain words**

- Between 3 and 3,000 numbers.
- Values are between -100,000 and 100,000.
- Each position may be used only once per triplet.
- The output must not contain duplicate triplets.
