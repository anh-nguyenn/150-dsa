You are given `n` nodes labeled `0` through `n - 1` and a list of undirected edges. Count how many separate connected components the graph has. A component is a maximal group of nodes where each node can reach every other node by following edges.

**Examples**

```text
n = 5, edges = [[0,1],[1,2],[3,4]]  -> 2
n = 5, edges = []                   -> 5
```

**Constraints, in plain words**

- Between 1 and 2,000 nodes.
- Up to 5,000 undirected edges.
- Edges connect two different nodes and are not repeated.
- A component may consist of a single node with no edges.
