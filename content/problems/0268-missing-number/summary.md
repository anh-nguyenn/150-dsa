An array contains `n` distinct numbers chosen from the range 0 through `n`. Exactly one number from that range is absent. Return the absent number.

**Example**

```text
nums = [3, 0, 1]  ->  2
```

The range for three numbers is 0 through 3, and 2 is the only value missing.

**Constraints, in plain words**

- The array length is between 1 and 10,000.
- Values are distinct and lie in 0 through `n`, where `n` is the length.
- Exactly one value from that range is missing.
