Given a binary tree, return its diameter: the number of edges on the longest path between any two nodes. The path does not have to pass through the root.

For `[1, 2, 3, 4, 5]`, the path `4 -> 2 -> 1 -> 3` uses three edges, so the answer is 3.

**Constraints, in plain words**

- The tree has between 1 and 10,000 nodes.
- Node values are between -100 and 100.
- Missing children are written as `null` in the level-order input.
