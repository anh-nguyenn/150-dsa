Given a list of words, split them into groups so that every word in a group is an anagram of the other words in that group. Return the groups in any order, and the words inside each group in any order.

**Example**

```text
["eat", "tea", "tan", "ate", "nat", "bat"]
->  [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
```

**Constraints, in plain words**

- Between 1 and 10,000 words.
- Each word has at most 100 characters and uses lowercase English letters.
- Anagrams contain the same letters with the same counts.
