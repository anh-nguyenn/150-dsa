An array of `n + 1` integers contains values from `1` to `n`, and exactly one value is repeated. Return that repeated value without changing the array and without using extra space proportional to `n`.

**Examples**

```text
[1, 3, 4, 2, 2]  ->  2
[3, 1, 3, 4, 2]  ->  3
```

**Constraints, in plain words**

- The array length is between 2 and 100,001, so `n` is at least 1.
- Every value is between 1 and `n`.
- Exactly one value appears more than once; it may appear several times.
- The array must not be sorted or modified.
