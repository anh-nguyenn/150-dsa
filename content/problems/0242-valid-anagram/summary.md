Two strings are anagrams when one can be rearranged into the other while using every character the same number of times. Given strings `s` and `t`, return `True` if they are anagrams and `False` otherwise.

**Example**

```text
s = "anagram", t = "nagaram"  ->  True
s = "rat",     t = "car"      ->  False
```

**Constraints, in plain words**

- Both strings contain only lowercase English letters.
- Each length is between 1 and 50,000.
- Order does not matter, but the count of each letter does.
