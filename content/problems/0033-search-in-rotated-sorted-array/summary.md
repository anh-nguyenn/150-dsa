A sorted array with distinct values was rotated. Return the index of a target, or -1 if it is absent.

```text
nums = [4,5,6,7,0,1,2], target = 0  ->  4
nums = [4,5,6,7,0,1,2], target = 3  ->  -1
```

**Constraints, in plain words**

- Between 1 and 5,000 numbers.
- All values are distinct.
- The array is sorted and then rotated, possibly zero times.
- The answer must be found without scanning every element.
