A matrix has rows sorted left to right, and each row starts with a value larger than the previous row's last value. Decide whether a target value appears in the matrix.

```text
[[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3   ->  true
target = 13                                            ->  false
```

**Constraints, in plain words**

- Between 1 and 100 rows and 1 and 100 columns.
- Every row is sorted ascending.
- The first value of a row is greater than the last value of the row above.
- Values lie between -10,000 and 10,000.
