For every integer from 0 through `n`, report how many 1 bits its binary form contains. Return the counts as an array of length `n + 1`.

**Example**

```text
n = 5  ->  [0, 1, 1, 2, 1, 2]
```

Here index 3 has binary `11`, so its entry is 2.

**Constraints, in plain words**

- `n` is between 0 and 100,000.
- The answer contains one entry for each value from 0 to `n`.
- Entry `i` counts the 1 bits in `i`.
