Given a binary tree, return its level-order traversal as a list of levels, from top to bottom and left to right within each level.

`[3, 9, 20, null, null, 15, 7]` becomes `[[3], [9, 20], [15, 7]]`.

**Constraints, in plain words**

- The tree has between 0 and 2,000 nodes.
- Node values are between -1,000 and 1,000.
- Missing children appear as `null` in the level-order input.
