Given a list of integers, decide whether any value appears at least twice. Return `True` when a repeat exists and `False` when every value is unique.

**Example**

```text
nums = [1, 2, 3, 1]  ->  True
nums = [1, 2, 3, 4]  ->  False
```

**Constraints, in plain words**

- The list has between 1 and 100,000 entries.
- Values may be negative, zero, or positive.
- Only a yes/no answer is required.
