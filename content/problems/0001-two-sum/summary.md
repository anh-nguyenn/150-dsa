You are given a list of integers and a target integer. Return the indices of the two numbers that add up to the target.

Each input has exactly one valid pair, and the same index may not be used twice. The answer can be returned in either order.

**Example**

```text
nums = [2, 7, 11, 15], target = 9  ->  [0, 1]
```

**Constraints, in plain words**

- Between 2 and 10,000 numbers.
- Each number is between -10^9 and 10^9.
- Exactly one pair works.
- Indices must be different.
