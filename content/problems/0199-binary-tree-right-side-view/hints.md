## Hint 1

Think about what you would see if you scanned the tree one horizontal layer at a time. Which node on a layer matters?

## Hint 2

A queue lets you process every node on a level before moving down. How can you tell where one level stops and the next begins?

## Hint 3

Record the queue size at the start of each level, process exactly that many nodes, and keep the value of the last one.
