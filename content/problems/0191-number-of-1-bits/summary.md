Given a non-negative integer, count how many of its binary digits are 1. This count is often called the Hamming weight or population count.

**Examples**

```text
n = 11  (binary 1011)  ->  3
n = 128 (binary 10000000)  ->  1
```

**Constraints, in plain words**

- The input is between 0 and 2^32 - 1.
- Only the 32-bit binary representation is considered.
- Return a plain integer count.
