Given a binary tree, return the number of nodes on the longest path from the root down to a leaf. An empty tree has depth 0.

`[3, 9, 20, null, null, 15, 7]` has depth 3, for example along `3 -> 20 -> 15`.

**Constraints, in plain words**

- The tree has between 0 and 10,000 nodes.
- Node values are between -100 and 100.
- Missing children are represented by `null` in the level-order input.

[Maximum Depth of Binary Tree on LeetCode](https://leetcode.com/problems/maximum-depth-of-binary-tree/)
