A non-negative integer is stored as a list of decimal digits, most significant first, with no leading zeros except for the number zero itself. Add one and return the resulting digits.

**Example**

```text
[1, 2, 3] -> [1, 2, 4]
[9, 9, 9] -> [1, 0, 0, 0]
```

**Constraints, in plain words**

- Between 1 and 100 digits.
- Each digit is from 0 through 9.
- The first digit is nonzero unless the list is exactly `[0]`.
- The number may be too large for a fixed-size integer, so work directly on the digits.
