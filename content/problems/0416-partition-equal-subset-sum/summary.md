Decide whether the array can be split into two groups whose sums are equal. Every element must go to exactly one group.

**Example**

```text
[1, 5, 11, 5]  ->  true    (11 and 1 + 5 + 5)
[1, 2, 3, 5]   ->  false   (the total 11 is odd)
```

**Constraints, in plain words**

- Between 1 and 200 numbers.
- Each number is between 1 and 100.
- Elements cannot be split between the two groups.
