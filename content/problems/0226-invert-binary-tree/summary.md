Given the root of a binary tree, mirror it: every node's left and right subtrees trade places. Return the root of the inverted tree.

For `[4, 2, 7, 1, 3, 6, 9]`, the result is `[4, 7, 2, 9, 6, 3, 1]`, because the two children of every node have swapped.

**Constraints, in plain words**

- The tree has between 0 and 100 nodes.
- Node values are between -100 and 100.
- A missing child appears as `null` in the level-order input.
