Return the length of the longest strictly increasing subsequence of an integer array. The chosen values keep their original order but do not have to be adjacent.

**Example**

```text
[10, 9, 2, 5, 3, 7, 101, 18]  ->  4   (for example 2, 3, 7, 101)
[7, 7, 7, 7]                  ->  1
```

**Constraints, in plain words**

- Between 1 and 2,500 numbers.
- Each number is between -10,000 and 10,000.
- Increasing means strictly greater; equal values do not extend a subsequence.
