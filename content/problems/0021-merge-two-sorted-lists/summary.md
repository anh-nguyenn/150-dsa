Merge two sorted singly linked lists into one sorted list. Reuse the existing nodes; the result should contain every value from both inputs exactly once.

**Example**

```text
[1, 2, 4] and [1, 3, 4]   ->   [1, 1, 2, 3, 4, 4]
```

**Constraints, in plain words**

- Each list holds between 0 and 50 nodes.
- Values are between -100 and 100.
- Each input is already in non-decreasing order.
- Either or both inputs may be empty.
