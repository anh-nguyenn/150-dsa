Given an array sorted in ascending order and a target value, return the index where the target appears, or -1 if it is absent.

```text
nums = [-1,0,3,5,9,12], target = 9  ->  4
nums = [-1,0,3,5,9,12], target = 2  ->  -1
```

**Constraints, in plain words**

- Between 1 and 10,000 numbers.
- Values are sorted from smallest to largest and are all different.
- Each value is between -10,000 and 10,000.
- The target appears at most once, or not at all.
