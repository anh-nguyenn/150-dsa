Given an array and a window size `k`, return the maximum value in every contiguous window of length `k`, in left-to-right window order.

**Example**

```text
nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3
->  [3, 3, 5, 5, 6, 7]
```

**Constraints, in plain words**

- Between 1 and 100,000 numbers.
- Values are between -10,000 and 10,000.
- `k` is at least 1 and at most the array length.
- Output exactly one maximum per window, in order.
